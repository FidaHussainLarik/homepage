# Fida Hussain — Personal Portfolio

A responsive personal portfolio built with React, Vite, and Material UI.

## Live Demo

[homepage-alpha-steel.vercel.app](https://homepage-alpha-steel.vercel.app/)

## Structure

- `src/data/portfolioData.js` — centralized portfolio content.
- `src/theme/theme.js` — the MUI theme and global component defaults.
- `src/components/` — reusable layout, navigation, and project UI.
- `src/sections/` — complete semantic page sections.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The generated `dist/` directory can be deployed to Vercel or another static hosting provider. Vercel detects Vite automatically when the project is connected to GitHub.
